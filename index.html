동률 처리 기준 & 예시

1. 순위 산정 우선순위

리그전(조별 경기) 순위는 아래 기준을 순차적으로 적용하여 결정합니다.

  1. 승수 (Wins)
    전체 경기 승리 횟수가 많은 순서
  2. 승자승 (Head-to-Head)
    승수가 같은 선수들끼리의 맞대결 승수가 많은 순서 (3인 이상 포함)
  3. 세트 득실 (Set Difference)
    이긴 세트에서 진 세트를 뺀 값이 큰 순서
    * 동률 시 변별력을 위해 내부적으로는 득실률(득세트/총세트)을 계산하여 결정합니다.
  4. 세트 다득 (Set For)
    총 이긴 세트가 많은 순서
  5. 공동 순위 (Tie)
    모든 기준이 같을 경우 공동 순위로 처리 (필요 시 수동 확정 가능)

2. 동률 처리 예시 (3인 동률 시)

상황: A, B, C 모두 1승 1패

  • A vs B : A 승 (2–0)
  • B vs C : B 승 (2–1)
  • C vs A : C 승 (2–1)

판단 과정

  1. 승수: 모두 1승으로 동일
  2. 승자승: 세 명 간의 맞대결도 각각 1승 1패로 동일
  3. 세트 득실 비교
    참가자 득/실 득실(차)
    A 3/2 +1
    B 2/3 -1
    C 3/3 0

최종 순위: A(1위) > C(2위) > B(3위)

3. 참고 사항

  • 득실률 계산: (본인 득점 세트합) / (본인 전체 경기 세트합)
  • 동률 해결이 안 될 경우 순위 셀을 클릭하여 수동으로 순위를 확정할 수 있습니다.
